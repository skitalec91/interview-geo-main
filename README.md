Geoblock

Задача: дать пользователям возможность выбирать город

- Город по-умолчанию должен определяться по ip
- Пользователь должен иметь возможность указать город вручную
- Пользователь должен иметь возможность определить город встроенными в браузер средствами
- Пользователь, поменявший настройки, должен иметь возможность вернуть поведение по-умолчанию

Запуск сервера api: `npm run mocks`

Запуск проекта: `npm start`
